# Thesis

[Read the thesis (PDF)](EN%20SANATKUMAR%20KAKADIYA%20DEFI%20VERIFICATION.pdf): *Securing AI Agents in Decentralized Finance through Graph-Based Intent Verification*.

The [editable LaTeX project](source/thesis.tex) accompanies the final PDF. The chapters are in [content/](source/content/), the references in [bibliography.bib](source/bibliography.bib), and the editable diagrams and exported figures in [figures/](source/figures/). The [Digital Appendix chapter](source/appendix/digital_appendix.tex) describes the accompanying [prototype](../source/), [experiments](../evaluation/), and [Neo4j snapshot](../evaluation/graph/submission/).

## Building the source

From `thesis/source/`, run `latexmk -pdf thesis.tex` with a full TeX Live installation. The PDF linked above is the supplied final report. The editable files are from the accompanying [final ZIP](EN%20SANATKUMAR%20KAKADIYA%20DEFI%20VERIFICATION.zip).
